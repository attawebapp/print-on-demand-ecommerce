# Print On Demand eCommerce Website

![Project Preview](screencapture.png)

A modern eCommerce website created for a print-on-demand business. The project focuses on clean design, product presentation, and a responsive shopping experience.

## Features

- Responsive Layout
- Product Categories
- Featured Products
- Trending Collections
- Blog Section
- Customer Reviews
- Contact Page
- Newsletter Subscription

## Technologies

- HTML5
- CSS3
- Bootstrap
- JavaScript
- PHP
